# JobsOxo — "Ledger" restyle (Replit handoff)

Applies the classical/editorial look from the **Conor Foy Plaster** site to the whole
JobsOxo app. Because the app is entirely token-driven (shadcn semantic tokens plus the
custom `--jox-*` / `--b-*` set), **replacing two token blocks restyles all 26 pages at
once** — no per-page work.

Source of the look: the CFP site's `classical` design system (Cormorant Garamond over
Lora, oxblood accent as stroke, hairline rules, 4px radii, whisper elevation).

---

## Apply it — 3 required steps

### 1. Replace `client/src/index.css`
Drop in `index.css` from this folder. Only the `:root` and `.dark` token blocks changed
plus a small `@layer base` addition for headings, tabular figures, links and focus rings.
**The elevate system, utilities and print rules are byte-identical to your current file** —
nothing structural was touched.

### 2. Replace `tailwind.config.ts`
Drop in `tailwind.config.ts` from this folder. Changes: radius scale to 2/4/7px, a
`font-display` family, and the four `status.*` presence dots pulled into the palette.
Everything else is identical.

### 3. Add Cormorant Garamond to the font link in `client/index.html`
Lora is already loaded. Cormorant Garamond is not. In the big Google Fonts `<link>`,
add this family (alphabetical, right after `family=Architects+Daughter`):

```
family=Cormorant+Garamond:ital,wght@0,300..700;1,300..700&
```

While you're there you can drop `Inter` and `IBM Plex Mono` from that URL — nothing
references them after this change.

---

## Strongly recommended — the outlined primary button

The single change that most defines this look, and the one thing tokens alone can't do:
**the primary button is an oxblood outline, not a solid fill.** In
`client/src/components/ui/button.tsx`, change the `default` variant:

```diff
- default: "bg-primary text-primary-foreground border border-primary-border hover:bg-primary/90"
+ default: "bg-transparent text-primary border border-primary hover:bg-primary/10 active:bg-primary/[0.18]"
```

Keep a solid fill only for a final irreversible confirm inside a dialog. If you skip this
step the app will still be fully themed, but oxblood-filled buttons will read heavier than
the classical system intends.

## What changes visually

- **Type**: Inter → Lora (body), headings → Cormorant Garamond. Bold retired; `h1`/`h2` set at weight 400.
- **Numbers**: IBM Plex Mono → **retired**. `--font-mono` resolves to Lora, and `.font-mono`, all table cells, and `[data-tabular]` get `font-feature-settings: 'tnum'` so money still aligns in a column. Nothing in your JSX has to change.
- **Ground**: near-white grey → pale blue #ebf2fa; ink → deep green-black #132a13.
- **Accent**: blue #2563eb → oxblood #640d14, used as stroke.
- **Radii**: 9/6/3px → 7/4/2px.
- **Shadows**: were transparent no-ops; now genuine ink-tinted whispers.
- **Status badges**: hue kept for meaning, saturation pulled back. Oxblood/brick now reserved for money-critical states.
- **Smart Inbox banner**: the `--gem-bg` gradient is gone — flat surface, hairline border, oxblood ✳ mark. (Also finishes the earlier "it isn't Gemini" cleanup.) A new `--gem-mark` token carries the mark color.
- **Charts**: neon five → oxblood, gold, sage, slate, plum.
- **Dark mode**: still ships. Inverts to a deep warm near-black ("Colophon") with **gold** as the accent, since oxblood dies on a dark ground. Your existing toggle keeps working with no code change.

## Token compatibility

Every token name in your current `index.css` still exists with the same name — only values
changed. One token was **added** (`--gem-mark`). So any component reading `var(--panel)`,
`var(--b-green-fg)`, `var(--av3)` etc. keeps working untouched.
